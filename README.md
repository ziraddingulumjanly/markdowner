## Markdown the documents 

- Convert even large documents with hundreds or thousands of pages into Markdown in seconds.
- Transform PDFs and EPUBs into clean Markdown that's easier for AI models, LLMs, and RAG pipelines to process.
- Files are processed locally in your browser without uploading documents to a server.
- No installation, accounts, or API keys required. Just upload, convert, and automatically download your Markdown file.

## Things will be developed 

- Text-based PDFs only (PDF.js); scanned PDFs need OCR, which is not included.
- DRM-free EPUBs only (JSZip + Turndown). Embedded images are not exported.
- Conversion libraries load from public CDNs, so internet access is required, though document contents remain in your browser.
- Complex PDF layouts / tables may lose formatting.
